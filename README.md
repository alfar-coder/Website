# Álfar Smári

A buildless personal portfolio based on [Figma frame 429:906](https://www.figma.com/design/BvJJ66MR43HD20sgNcUO9I?node-id=429-906). Serve the repository root with a static HTTP server. No installation or build is required.

The page uses Suisse Intl Book and the Nolla photo exported from the Figma frame. The gallery preserves the four cards in the design and supports horizontal scrolling.
