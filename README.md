# Álfar Smári

A buildless personal portfolio based on [Figma frame 436:1422](https://www.figma.com/design/BvJJ66MR43HD20sgNcUO9I?node-id=436-1422). Serve the repository root with a static HTTP server. No installation or build is required.

The page uses Suisse Intl Book, the Manneskja mark, and the Nolla photo from Figma. The gallery snaps to the center of each card, and the glow follows the centered card.
